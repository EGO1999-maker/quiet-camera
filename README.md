# Quiet Camera

전면·후면 전환과 사진 저장에 집중한 개인용 아이폰 카메라입니다.

- iOS 16 이상, 아이폰, 세로 화면
- 전면 / 후면 카메라, 연속 자동초점·노출(기기 지원 시)
- 촬영 버튼을 누른 다음 전달되는 영상 프레임을 JPEG로 저장
- 1080p 영상 우선, 미지원 시 기기 지원 해상도 사용
- 전면 사진은 미리보기처럼 좌우 반전된 상태로 저장
- 화면 전체를 채우는 카메라 미리보기와 화면 위의 촬영·전환 버튼
- 두 손가락·슬라이더 확대/축소, 1배 복귀 (기기 지원 범위 안에서 최대 8배 디지털 줌)
- 화면을 눌러 초점·노출 위치 지정 (지원 기기), ±2 EV 이내 밝기 보정과 자동 복원
- 촬영 순서대로 3열 썸네일 갤러리, 사진을 선택해 최대 5배 확대·이동, 확인 후 원본 삭제
- 미리보기의 화면 비율에 맞춰 가운데를 잘라 저장 (전면 좌우 반전 유지)
- 촬영 시 사진 추가 권한만 요청. 설정에서 선택한 사진·전체 사진 접근을 별도로 요청 가능
- 마이크·위치 권한 없음. 사진 접근 범위의 실제 허용·변경은 아이폰 시스템에서 사용자가 선택
- 로그인, 광고, 분석 SDK, 네트워크 전송 없음

정지사진 셔터 API, 동영상 녹화, 사운드 재생은 사용하지 않습니다. 기본 카메라의 고해상도 정지사진·야간/HDR 처리와는 품질이 다릅니다. 실제 기기와 iOS에서 무음, 방향, 저장 동작을 확인해야 합니다.

## v1.3.0

왼쪽 아래 갤러리에서 먼저 촬영한 사진부터 3열로 표시합니다. 사진을 누르면 크게 보고 확대·이동할 수 있습니다. 휴지통 → 삭제 확인 → iOS 승인 후 사진 보관함의 원본을 삭제합니다. 취소·실패하면 목록에서 제거하지 않습니다. iCloud 사진 사용 시 원본 삭제는 연결 기기에도 반영됩니다.

촬영한 사진의 식별자와 순서를 앱 내부에 원자적으로 저장해 재실행 후에도 유지합니다. 원본 이미지를 앱에 중복 보관하지 않습니다. 촬영은 사진 추가 권한만으로 가능하며, 갤러리에는 선택한 사진 또는 전체 사진 접근이 필요합니다. 제한된 권한으로 보이지 않는 사진의 기록은 지우지 않고 권한 안내를 표시합니다. 사진 앱에서 삭제한 사진은 표시에서 제외합니다.

촬영 기록은 v1.3.0 이후 저장분부터 남습니다. 이전 버전의 사진은 사진 앱에서 확인할 수 있습니다. 앱 삭제·재설치 시 앱 내부 목록은 사라지므로 기존 앱을 업데이트하세요. 사진 보관함의 원본은 앱 삭제와 별개입니다.

확인 항목: 세 장 이상 촬영 → 촬영 순서로 표시 → 가운데 사진 선택/확대 → 삭제 취소 시 유지 → 삭제 승인 시 해당 사진만 제거 → 마지막 사진 삭제 후 빈 목록 → 앱 재실행 후 순서 유지. 제한된 사진 권한, 설정에서 권한 변경, 사진 앱 외부 삭제, iCloud 원본 다운로드 실패/재시도도 실기기에서 확인하세요.

빌드에서는 GalleryIndexTests로 재실행 후 순서 보존, 기기 시간 변경에도 촬영 순서 유지, 중복 방지, 선택한 식별자만 삭제, 손상된 목록 처리까지 검사합니다.

## v1.2.0 (이전 버전)

줌 → 터치 초점·밝기 → 저장 사진 확인 → 미리보기와 저장 구도 일치를 추가했습니다. 사진을 보는 동안 카메라를 멈추고 닫으면 다시 시작합니다. 사진 보기에는 이번 실행에서 마지막으로 저장한 사진을 표시하며, 기존 앨범 전체를 탐색하는 기능은 아닙니다. 기본 광각 렌즈를 사용하므로 0.5배 초광각·별도 망원 렌즈 전환은 포함하지 않습니다. 확대하면 해상도가 떨어질 수 있습니다. 가로 촬영은 아직 지원하지 않습니다.

카메라 화면의 촬영·설정 버튼은 사진에 들어가지 않습니다. 화면에 표시되는 영상의 가운데 영역을 동일 비율로 저장하며, 픽셀 단위 반올림으로 1픽셀 이내 차이가 있을 수 있습니다.

## v1.1.0 (이전 버전)

미리보기의 바깥 여백을 없애고 전체 화면으로 확대했습니다. 화면을 채우기 때문에 가장자리가 일부 잘려 보일 수 있으며, 저장되는 JPEG는 원본 프레임 전체입니다. 오른쪽 위 설정에서 카메라·사진 권한 상태를 확인하고 사진 접근 범위를 요청하거나 아이폰 앱 설정으로 이동할 수 있습니다. 더 넓은 사진 권한을 거부해도 사진 추가 권한이 허용되어 있으면 촬영·저장은 계속 사용할 수 있습니다.

## 맥 없이 빌드하기

1. 이 프로젝트를 **공개 GitHub 저장소**의 최상위에 올립니다. `.github` 폴더를 포함합니다.
2. **Actions → Build iPhone IPA → Run workflow**를 실행합니다. `main`에 코드 변경을 올려도 실행됩니다.
3. 성공한 실행의 **Artifacts → QuietCamera-IPA**를 다운로드해 ZIP을 풉니다.
4. 버전이 붙은 `QuietCamera-v1.1.0.ipa` 같은 파일을 아이폰에 전달하고 SideStore의 **My Apps → +**에서 선택합니다.
5. SideStore로 서명·설치한 후 앱을 열어 카메라와 사진 추가 권한을 허용합니다.

IPA는 서명되지 않은 상태이며 SideStore가 서명합니다. 빌드 서버에 Apple 계정·암호·인증서를 넣을 필요가 없습니다. 기존 앱 때문에 무료 계정 설치 한도에 도달했다면 SideStore에서 앱 슬롯을 확보해야 합니다. 설치 완료를 위해 기기에 따라 개발자 모드 활성화가 필요합니다.

무료 표준 macOS 실행 환경만 사용하며 비공개 저장소에서는 빌드를 건너뜁니다. 결과물 보관기간은 3일입니다. 다운로드한 IPA는 보관해 두세요. 7일 서명 갱신만 할 때는 재빌드하지 않습니다.

## 맥에서 직접 빌드하기

Xcode 및 Python 3가 있는 맥에서 `bash scripts/build_ipa.sh`를 실행합니다. 결과는 `build/QuietCamera-v<앱 버전>.ipa`입니다. 앱 버전을 읽어 파일명에 자동으로 붙이며, 체크섬 파일에도 같은 버전이 포함됩니다. `QuietCamera.xcodeproj`를 Xcode로 열 수도 있습니다. 프로젝트를 재생성하려면 `python3 scripts/generate_project.py`를 실행합니다.

## 실기기 확인

- 전·후면에서 각각 촬영: 사진 앱에 한 장씩 저장되는지
- 전면: 미리보기와 저장된 사진의 좌우 방향이 같은지
- 벨소리 켬/무음 모드 각각: 촬영 소리가 없는지
- 앱을 나갔다 돌아오기, 화면 잠금 후 복귀: 촬영 재개되는지
- 카메라 권한 거부 후 설정에서 허용: 복구되는지
- 사진 추가 권한 거부: 저장 성공을 표시하지 않고 안내하는지
- 연속으로 버튼 누르기: 저장 중 중복 요청을 차단하는지
- 전체 화면 미리보기에서 노치·홈 인디케이터가 버튼을 가리지 않는지
- 설정에서 사진 추가만 허용한 뒤 저장, 선택한 사진 허용, 전체 사진 허용 각각 확인
- 넓은 사진 접근 거부 후 사진 추가만 허용한 상태에서도 저장되는지
- 아이폰 설정에서 권한 변경 후 복귀하면 현재 범위가 갱신되는지
- 전·후면에서 핀치·슬라이더로 확대 및 축소, 1배 복귀, 최대 배율 제한 확인
- 상하좌우 피사체를 눌러 터치 초점 확인 (특히 전면 좌우 반전 좌표)
- 밝기 최솟값·최댓값·자동 복원 및 카메라 전환 후 표시 상태 확인
- 사진 썸네일을 열어 확대·이동·두 번 탭 복원, 닫은 후 촬영 재개 확인
- 화면 가장자리에 표식을 두고 저장 사진과 미리보기의 경계가 일치하는지 확인

빌드 전 `CaptureGeometryTests.swift`로 세로·가로·정사각형·아이폰 화면 비율의 크롭, 중심 정렬, 범위와 잘못된 입력 처리를 검증합니다. 기기 카메라의 실제 초점·줌·노출 동작은 실기기에서 확인해야 합니다.

Windows에서는 iOS 앱을 컴파일하거나 카메라 하드웨어를 검증할 수 없습니다. GitHub Actions의 성공과 실제 아이폰 테스트를 구분해 확인하세요.
