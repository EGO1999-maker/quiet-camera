# Quiet Recorder 1.0.0

아이폰과 Apple Watch에서 선택한 기기의 내장 마이크로 녹음하는 별도 앱입니다. 앱 자체의 시작/종료 효과음과 햅틱은 재생하지 않습니다. 운영체제 마이크 사용 표시를 숨기지 않습니다. 재생 버튼은 실제 녹음 오디오를 재생합니다.

## 사용

- 아이폰: 앱 실행 → 마이크 허용 → 녹음 시작/종료. 워치 원격 시작을 쓰려면 ‘워치 원격 녹음’을 켭니다.
- 워치: 녹음 기기에서 **워치 / 아이폰** 선택. 워치는 자체 마이크, 아이폰은 연결된 아이폰의 내장 마이크를 사용합니다. 이어폰 마이크로 자동 대체하지 않습니다.
- 워치 파일은 로컬에 저장된 뒤 Watch Connectivity로 아이폰에 전송합니다. 전송은 연결·OS 스케줄에 따라 늦어질 수 있습니다. 아이폰에서 파일 저장에 성공한 확인을 받아야 전송 완료로 표시하며 워치 원본은 자동 삭제하지 않습니다.
- 두 기기에서 재생·개별 삭제, 아이폰에서 공유/파일 앱 내보내기를 지원합니다. 파일은 최신순이며 출처·날짜·길이를 표시합니다. 앱 삭제 전 필요한 녹음은 내보내세요.

## 현실적인 제약

- 최소 iOS 17, watchOS 10. 사용자 목표 기기는 Series 9 / watchOS 26.6입니다. 해당 기기에서 아직 테스트하지 않았습니다.
- **잠긴 아이폰 또는 백그라운드에서 새 원격 녹음이 항상 시작된다고 보장하지 않습니다.** Watch Connectivity가 앱을 깨워도 마이크 세션 활성화는 별도의 OS 판단입니다. 시작 실패 시 아이폰 앱을 전면에 열도록 안내합니다. 가짜 무음 재생이나 사전 마이크 녹음으로 앱을 살려두지 않습니다.
- 시작한 녹음은 백그라운드 오디오 모드로 유지합니다. 전화·시스템 오디오 중단 시 파일을 마무리하고 다시 사용자가 시작하도록 합니다. 무제한 시간/배터리 지속을 보장하지 않습니다.
- 원격 명령은 즉시 메시지로만 전송하고 8초 뒤 만료합니다. 중복 요청은 한 번만 실행하며 종료 명령은 특정 녹음 ID에만 적용됩니다. 응답이 없으면 성공으로 표시하지 않습니다.
- **워치 포함 IPA를 빌드하는 것과 실제 설치는 별개입니다.** 현재 SideStore 환경에서 워치 앱 서명·설치·갱신은 검증되지 않았습니다. 공식 실기기 개발 경로는 Mac/Xcode와 적절한 서명/프로비저닝이며, TestFlight 배포에는 개발자 프로그램 설정이 추가로 필요합니다.
- 전체 IPA는 `QuietRecorder-v1.0.0.ipa`, 아이폰 단독 설치용은 `QuietRecorder-iPhone-v1.0.0.ipa`입니다. 둘 다 서명 전 파일입니다. 아이폰 단독판에는 워치 앱이 포함되지 않습니다.
- 설치 대안으로 [Watch 지원 SideStore 개조판](https://github.com/9andmoai/Fairway)이 공개돼 있습니다. 작성자가 Windows·무료 계정으로 자신의 앱 설치와 수동 갱신에 성공했다고 보고했지만, 다른 앱과 장기간 자동 갱신은 검증하지 않았습니다. 이 프로젝트에서 해당 개조판을 설치하거나 검증한 것은 아닙니다. 기존 SideStore를 자동 교체하지 않습니다.

## 빌드 / 검증

macOS/Xcode에서 `bash QuietRecorder/scripts/build.sh`. 순수 Foundation 테스트는 명령 만료, 중복 종료 방지에 필요한 세션 매칭, 메타데이터 왕복을 확인합니다. CI는 iOS와 watchOS 아카이브 컴파일, 내장 watch 앱·마이크 권한·백그라운드 모드·실행 파일 패키징을 확인합니다.

실기기 확인 항목: 양쪽 마이크 권한 거부/허용, 실제 입력 기기, 무음 모드와 비무음 모드에서 시작/종료음, 잠금 후 계속 녹음, 잠긴 아이폰 원격 시작 성공/실패 안내, 통화 중단, 연결 끊김 및 재연결, 전송 확인 후 양쪽 파일 재생, 재서명 후 워치 설치 유지.
